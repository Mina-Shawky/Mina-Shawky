## 🎬 Featured Projects

### 🎟️ TicketZ — Cinema Ticket Booking Platform

A cinema ticket booking and movie management platform built with **ASP.NET Core MVC**.

**Key Features:**

* 🎬 Movie browsing and search.
* 🎭 Movies, actors, producers, and cinemas management.
* 🛒 Shopping cart for adding and removing tickets.
* 💳 PayPal Checkout API integration.
* 🔐 Admin dashboard.
* ✏️ Full CRUD operations.
* 🔎 LINQ-based querying and filtering.
* 🗄️ Entity Framework Core & SQL Server.
* 🏗️ Repository Pattern.
* ⚡ JavaScript & jQuery interactions.

**Tech Stack:**
`C#` `ASP.NET Core MVC` `Entity Framework Core` `LINQ` `SQL Server` `Repository Pattern` `Bootstrap` `JavaScript` `jQuery` `PayPal API`

### 🎬 CinemaTV — Movie Management Platform

A movie management and display web application built using **ASP.NET Core MVC**.

**Key Features:**

* 🎥 Display movies and movie information.
* ➕ Add new movies.
* ✏️ Update movie information.
* 🗑️ Delete movies.
* 🔎 Search and query movie data.
* 🗄️ Database integration using Entity Framework Core.
* 📊 LINQ for querying and filtering.
* 🎨 Responsive UI using Bootstrap, HTML5, CSS3, and jQuery.
* 🏗️ MVC Architecture.

**Tech Stack:**
`C#` `ASP.NET Core MVC` `Entity Framework Core` `LINQ` `SQL Server` `HTML5` `CSS3` `Bootstrap` `JavaScript` `jQuery`
